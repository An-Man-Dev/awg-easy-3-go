# AWG Panel

[English](README.md) · **Русский**

Лёгкая веб-панель для самостоятельного размещения **AmneziaWG 3**, написанная на Go с SQLite. Управляйте устройствами, пользователями и настройками VPN из браузера.

- Отдельные аккаунты администраторов и пользователей, добровольная двухфакторная аутентификация.
- Общая сеть для домашних устройств и доступ только в интернет для гостевых.
- Ссылки подключения, QR-коды и конфигурационные файлы, возможность отключить хранение клиентских приватных ключей.
- Зашифрованный экспорт и импорт конфигурации для переезда на другой сервер.

**Альфа:** проект активно развивается. Этот выпуск фиксирует базовую схему БД; дальнейшие изменения схемы должны сохранять данные через версионированные миграции.

## Быстрый старт

Нужен Linux-сервер с правами root, **Docker Engine и Docker Compose v2**, Git и `/dev/net/tun`. Установщик также использует стандартные утилиты Linux, включая Bash и `ip`. Разрешите входящий **UDP 51820** в firewall сервера и провайдера либо откройте выбранный вами порт VPN.

### 1. Установите панель

```sh
git clone --branch main --single-branch https://github.com/An-Man-Dev/awg-easy-3-go.git /tmp/awg-panel-src
cd /tmp/awg-panel-src
sudo ./install.sh
cd /
```

Укажите публичный IP или домен VPN-сервера. Для простого запуска оставьте порты по умолчанию и ответьте **No** на предложение внешнего доступа к панели. Задайте пароль администратора или оставьте поле пустым для генерации пароля.

Установщик соберёт образ и разместит приложение в `/opt/awg-panel`. После установки из `main` временный каталог с исходниками удаляется.

### 2. Подключите первое устройство

На сервере выведите начальный профиль домашнего устройства:

```sh
sudo docker compose -f /opt/awg-panel/docker-compose.yml exec -T panel ./awg-panel --bootstrap
```

Импортируйте выведенную ссылку `vpn://` в **AmneziaVPN** или скопируйте конфигурацию в клиент с поддержкой используемых сервером параметров AmneziaWG 3. Включите туннель. Вывод содержит приватные ключи — не публикуйте его.

### 3. Откройте панель

При подключённом VPN откройте **http://10.8.0.1:8881** и войдите под логином **`admin`** с паролем, заданным при установке.

Если пароль был сгенерирован, прочитайте его на сервере:

```sh
sudo cat /opt/awg-panel/admin-password
```

Добавляйте устройства в **My devices**, управляйте пользователями в **Accounts**, меняйте настройки сервера через меню. Двухфакторная аутентификация подключается в **Two-factor**.
